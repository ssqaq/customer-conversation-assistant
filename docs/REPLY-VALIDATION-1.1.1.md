# 1.1.1 回复规则验证

日期：2026-09-10。1.1.1 只增加了“高情商”触发词和具体解释，保留 1.1.0 的事实保护与自然表达规则。

| 场景 | 输入事实 | 期望行为 |
|---|---|---|
| 高情商催进度 | 客户说“你们怎么还没好，我已经催三次了”，记录没有确认交期 | 先回应已说出的等待和催问，再说明没有确认交期，给出核实或下一步；不能写“今晚一定完成” |
| 高情商退款 | 客户问“钱退了吗”，资料只有“申请已提交，尚未批准” | 直接说明申请和审批状态，不用长篇安慰，不写已到账或保证到账时间 |
| 高情商价格异议 | 客户说“太贵了”，资料只有暂定报价和未授权折扣 | 承接价格顾虑，保留报价条件，说明折扣未确认；不推断客户没钱、不羞辱、不虚构优惠 |

高情商在本 Skill 中是可核对的沟通动作，不是情商评分，也不是夸赞、套话、替客户猜情绪或增加承诺。

这三项用于规则回归；真实客户反馈、不同模型效果和宿主自动匹配率仍需要后续实测。
